# AGENTS.md

PaperPulse — a 7-stage exam-question mining pipeline (PDF/image/text → topics → study plan). Pure Python, no build/packaging config. Run all commands from the repo root.

## Commands

```bash
pip install -r requirements.txt          # Python 3.11+
pytest tests/ -v                         # full suite
pytest tests/test_ranker.py -v           # single file
pytest tests/test_ranker.py::TestRankClusters::test_high_frequency_ranks_first   # single test
python sample_data/generate_sample_data.py    # writes sample_data/DS_2019..2024.txt
streamlit run paperpulse/app.py
python -m evaluation.evaluate            # downloads all-MiniLM-L6-v2; rewrites docs/results.md
```

- `tests/` are synthetic/pure: they need **no** sentence-transformers download and **no** Tesseract. Only `evaluation/evaluate.py` downloads the embedding model.
- `pytest` finds the package via `tests/conftest.py` sys.path insertion; `app.py` does the same. There is no `paperpulse/__init__.py` (implicit namespace package) and no `pyproject.toml`/`pytest.ini`.

## Architecture

Pipeline stages live in `paperpulse/core/` and are orchestrated by `run_pipeline` in `paperpulse/core/pipeline.py`:

`extractor.py` (PDF→pages) → `splitter.py` (pages→question DataFrame) → `embedder.py` (texts→vectors, cached) → `clusterer.py` (cluster_id) → `labeler.py` (cluster_label) → `ranker.py` (priority + study plan). Each stage is also callable standalone for debugging.

- `run_pipeline` accepts `pdf_paths` (alias) or `file_paths`; `extract_pdfs` is an alias of `extract_files`.
- `app.py` **bypasses** `run_pipeline` in "sample mode": sample files are `.txt`, so it runs `extract_files → split_results → Embedder.encode_dataframe → assign_clusters → label_clusters → rank_clusters` directly (app.py:471-508).
- UI styling is all inline CSS in `app.py`. A repo-local skill for UI work exists at `.agents/skills/frontend-design/SKILL.md`.

## Repo-specific gotchas

- **Threshold source of truth is `DEFAULT_THRESHOLD = 0.44` in `paperpulse/core/clusterer.py`.** The README (`0.35`) and `docs/results.md` (`0.5`) disagree — trust the code, and the sidebar help text. `evaluate.py` only searches `THRESHOLDS` in 0.05 steps, so its reported "best" will not equal 0.44.
- **Same-paper constraint is on by default** (`constrain_same_paper=True` in `assign_clusters`/`cluster_embeddings`): any two questions sharing a `year` or `source_file` get their pairwise distance forced to `10.0`, so they can never merge. This is deliberate and central to results — don't "simplify" it away.
- Embedding cache defaults to `.embedding_cache/` at the **CWD**, keyed by SHA-256 of the sorted unique question texts + model name. Delete the dir to force re-encoding. Model is `all-MiniLM-L6-v2` with `normalize_embeddings=True`.
- OCR is optional: Tesseract detection runs at `extractor.py` import time. Without it, scanned pages are skipped with warnings instead of crashing. Extractors support `.pdf`, images (`IMAGE_EXTENSIONS`), and `.txt`.
- Priority weights are 0.5 frequency / 0.3 recency / 0.2 marks, configured both as constants in `ranker.py` and as `run_pipeline` args. The sidebar formula text in `app.py` is hardcoded — update both if weights change.
- `docs/results.md` is generated by `evaluation/evaluate.py`; never edit it by hand.
- Marks `None` is intentional (unknown ≠ zero) and resolved to `NEUTRAL_MARKS_DEFAULT = 5.0` downstream.
